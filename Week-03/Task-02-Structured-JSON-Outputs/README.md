# Task 2: Structured Outputs — Get Clean JSON From Any Prompt

## Objective
Design prompts that force a language model to return clean, valid JSON following a predefined schema for reliable integration into applications.

## Tools Used
- ChatGPT
- JSON Schema
- Prompt Engineering

- Created a prompt that only returns valid JSON.
- Tested the prompt using multiple sample inputs.
- Evaluated JSON parsing.
- Tested edge cases with messy inputs.
- Improved the prompt when necessary.
- Recorded a demonstration video.
