# Task 1: RAG Mini-Project — Chat With Your Own Document

## Objective
Build a simple Retrieval-Augmented Generation (RAG) system that answers questions using a user-provided document instead of relying only on the language model's built-in knowledge.

## Tools Used
- NotebookLM
- PDF Document
- Prompt Engineering

## Tasks Completed
- Uploaded a custom document.
- Asked multiple questions based on the document.
- Verified whether the responses were grounded in the document.
- Identified any hallucinated responses.
- Compared grounded responses with general AI responses.
- Recorded a demonstration video.

## Files Included
- RAG Mini Project.docx
- Demo Video.mp4

## Learning Outcomes
- Understood how Retrieval-Augmented Generation (RAG) improves answer accuracy.
- Learned the importance of grounding AI responses in external knowledge.
- Observed how hallucinations can occur and how RAG helps reduce them.
