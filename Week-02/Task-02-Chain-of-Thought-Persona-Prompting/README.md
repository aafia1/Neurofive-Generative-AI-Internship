# 🧠 Task 02 – Chain-of-Thought & Persona Prompting

## 📌 Objective

The objective of this task was to explore the impact of Chain-of-Thought (CoT) reasoning and Persona Prompting on AI-generated responses by comparing structured reasoning with standard prompting techniques.

The task demonstrates how assigning a role to the AI and encouraging step-by-step reasoning improves the quality, clarity, and accuracy of responses.

---

## 🎯 Learning Outcomes

- Understand Chain-of-Thought Prompting.
- Learn Persona-Based Prompting.
- Compare AI responses using different prompting strategies.
- Improve prompt effectiveness.
- Analyze reasoning quality.
