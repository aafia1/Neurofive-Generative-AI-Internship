# 🤖 Task 01 – Custom AI Chatbot with a System Prompt

## 📌 Objective

The objective of this task was to build a custom AI chatbot using a well-designed system prompt that guides the chatbot's behaviour, personality, and responses for a specific use case.

The chatbot was developed to demonstrate how system prompts influence AI-generated responses while maintaining consistency, accuracy, and user-friendly interactions.

---

## 🎯 Learning Outcomes

- Understand the purpose of System Prompts.
- Design an AI assistant with a predefined role.
- Control AI behaviour through prompt engineering.
- Build a reusable chatbot for a specific domain.
- Improve response consistency using prompt instructions.
