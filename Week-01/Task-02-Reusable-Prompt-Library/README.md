# Task 02 – Build Your First Reusable Prompt Library

## Objective

The objective of this task is to design a reusable prompt template using the following structure:

- Role
- Context
- Task
- Format
- Constraints

The template is then used to generate five different prompts for the same use case.

## Tools Used

- ChatGPT
- Microsoft Word

## Files Included

- 📄 Prompt_Library_v1.docx
- 🎥 Demo_Video.mp4

## Learning Outcome

This task demonstrates how reusable prompt templates improve efficiency, consistency, and scalability when interacting with AI systems.
